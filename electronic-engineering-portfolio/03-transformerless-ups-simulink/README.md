# 100 kW Transformerless UPS Model

A MATLAB/Simulink concept for an online double-conversion UPS with a three-phase input, DC link, battery branch and three-phase SPWM inverter.

## Highlights

- Three-phase input stage
- 480 V DC link
- Battery-backed operation
- Three-phase SPWM MOSFET inverter
- Startup and DC-bus response analysis
- Filtered 50 Hz output assessment
- First-pass current, capacitance and battery sizing

## Technologies

MATLAB, Simulink, Power Electronics, SPWM
