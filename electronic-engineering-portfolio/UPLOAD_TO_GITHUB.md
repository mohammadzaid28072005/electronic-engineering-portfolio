# How to upload this repository to GitHub

## Browser method

1. Sign in to GitHub.
2. Select **New repository**.
3. Name it `electronic-engineering-portfolio`.
4. Choose **Public**.
5. Do not initialise it with another README.
6. Create the repository.
7. Select **uploading an existing file**.
8. Upload the contents of this package in manageable batches.
9. Commit the files.

## Recommended improvement

GitHub's browser uploader may not preserve empty folders. The `.gitkeep` files included here preserve the folder structure.

## Before publishing original coursework

Remove:
- Student numbers
- Email addresses and phone numbers
- Passwords, Wi-Fi credentials and API keys
- Private feedback or marking information
- Files you do not own or have permission to publish
