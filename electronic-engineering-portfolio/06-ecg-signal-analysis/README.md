# ECG Signal Analysis

A MATLAB workflow for comparing relaxing and exercising ECG signals using detrending, filtering, peak detection and heart-rate estimation.

## Highlights

- Linear and polynomial detrending
- Butterworth filtering from approximately 0.5–40 Hz
- QRS/peak detection
- BPM estimation
- Comparison of resting and exercising segments
- Time-domain and frequency-domain visualisation

## Technologies

MATLAB, ECG, Signal Processing, Butterworth Filter, Peak Detection
