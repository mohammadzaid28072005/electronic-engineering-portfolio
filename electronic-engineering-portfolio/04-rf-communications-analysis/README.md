# RF and Communications Analysis

MATLAB and Simulink work covering radio propagation, link budgets, path loss, Fresnel-zone clearance, coverage, SINR, antenna behaviour, transmission lines, VSWR, 16-QAM and BER.

## Highlights

- 868 MHz propagation study
- Free-space path-loss calculations
- Fresnel-zone assessment
- Received-power, coverage and SINR analysis
- Antenna pattern investigation
- Transmission-line and VSWR analysis
- 16-QAM over AWGN
- BER comparison at different SNR values

## Technologies

MATLAB, Simulink, Antenna Toolbox, Site Viewer, RF, 16-QAM
