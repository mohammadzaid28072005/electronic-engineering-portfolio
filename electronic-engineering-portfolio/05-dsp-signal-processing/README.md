# Digital Signal Processing Exercises

A collection of MATLAB-based signal-processing exercises involving FFT analysis, IIR and FIR filter design, windowing, audio processing and frequency-domain analysis.

## Highlights

- IIR low-pass, band-stop and band-pass design
- FIR frequency-sampling methods
- Hamming and Hann windows
- FFT analysis
- Audio filtering and spectral inspection
- Impulse-invariant design techniques

## Technologies

MATLAB, DSP, FFT, FIR, IIR
