# Node.js IoT Web Platform

A web-based IoT monitoring application developed with Node.js, Express, REST endpoints, real-time updates and browser-based visualisation.

## Highlights

- REST API routes
- WebSocket/Socket.IO real-time updates
- Device status and historical readings
- Event logging
- Remote configuration
- JSON communication
- Serial and embedded-device integration

## Technologies

JavaScript, Node.js, Express, SQLite, Socket.IO, REST, JSON, HTML, CSS
