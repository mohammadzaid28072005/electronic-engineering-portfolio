# IoT Temperature Monitoring Platform

A multi-node embedded monitoring platform combining ESP32-S3 hardware, LM35 analogue temperature sensing, Wi-Fi telemetry, a Node.js/Express backend, SQLite persistence and a browser dashboard.

## Highlights

- ESP32-S3 firmware for ADC sampling, temperature conversion and connectivity management
- LM35 analogue sensor interface
- HTTP telemetry and persistent device configuration
- Node.js/Express backend with SQLite
- Real-time browser updates using Socket.IO
- MQTT bridging and communication-health telemetry
- Two-layer KiCad PCB with LiPo input and AP2112K 3.3 V regulation
- Structured debugging of power, ADC, Wi-Fi and MQTT issues

## Technologies

ESP32-S3, C/C++, Arduino, KiCad, Node.js, Express, SQLite, Socket.IO, MQTT, HTTP, JSON
